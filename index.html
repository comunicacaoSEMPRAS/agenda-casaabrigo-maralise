Como utilizar este sistema

Cadastre as visitas com a data, horários, finalidade, instituição ou visitante e profissional responsável. A agenda permite acompanhar a situação, registrar realização e consultar o histórico. Para atividades externas, selecione o tipo apropriado.

Proteção e sigilo: esta versão funciona somente neste navegador e salva dados no armazenamento local do dispositivo. Ela não possui login, servidor, sincronização entre computadores ou controle de acesso. Não é apropriada para guardar dados pessoais sensíveis, documentos judiciais, nomes de acolhidos ou imagens. Para uso institucional compartilhado, será necessária implantação com autenticação e armazenamento protegido.

Os dados podem ser exportados em CSV para conferência administrativa, mas o CSV também deve ficar em pasta de acesso restrito. O navegador pode apagar os registros ao limpar dados ou usar navegação privada. Faça cópias administrativas seguras.

Protótipo administrativo local • Proteja a privacidade dos acolhidos • Uso compartilhado exige hospedagem e autenticação.
